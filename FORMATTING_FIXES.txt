GradeNet Paper: Formatting Fixes Applied
================================================================================

Date: May 4, 2026
Issue: PDF formatting problems with special characters and algorithm display

================================================================================
PROBLEMS IDENTIFIED
================================================================================

1. Character Encoding Issues:
   - < and > symbols in verbatim blocks rendering as ¡ and ¿
   - Inconsistent math mode usage
   - Unescaped < > in regular text converted to incorrect Unicode

2. Algorithm Display:
   - Verbatim block not rendering cleanly
   - Poor formatting for pseudocode

3. Math Notation:
   - Numbers and operators not in math mode causing encoding issues

================================================================================
FIXES APPLIED
================================================================================

1. **Fixed Algorithm Pseudocode Formatting**
   - Replaced verbose algorithm environment with compact verbatim block
   - Simplified pseudocode to fit IEEE column width
   - Maintained all logic and clarity
   - Reduced whitespace while keeping readability

2. **Fixed Character Encoding**
   - Wrapped all < and > symbols in math mode: $<$, $>$
   - Example: "latency SLAs ($<100$ms)" instead of "(<100ms)"
   - Applied to all problematic instances throughout paper

3. **Improved Math Notation**
   - Wrapped numbers with units in math mode where appropriate
   - Example: "50\% threshold" → "50\% threshold" (percentage symbol properly formatted)
   - Ensured consistency in mathematical expressions

4. **Table Formatting**
   - Maintained proper column alignment
   - All communication volume indicators properly formatted

================================================================================
SPECIFIC CHANGES MADE
================================================================================

Change 1: SLA Violation Description
  Before: "strict latency SLAs (<100ms)"
  After:  "strict latency SLAs ($<100$ms)"

  Impact: Fixes encoding issue where < became ¡

Change 2: Grade Definitions
  Before: "Communication volume < 2 GB"
  After:  "Communication volume $<2$ GB"

  Impact: All three grade definitions now properly formatted

Change 3: Decision Tree Rules
  Before: "If comm_vol < 2 GB: grade = 0"
  After:  "If comm\_vol $<2$ GB: grade $= 0$"

  Impact: Math mode wrapping fixes character encoding

Change 4: Bandwidth Slicing Steps
  Before: "guarantees <50ms latency"
  After:  "guarantees $<50$ms latency"

  - ">8 GB" → "$>8$ GB"
  - "<0.5ms" → "$<0.5$ms"
  - "<available bandwidth" → "$<$ available bandwidth"
  - ">70%" → "$>70\%$"

Change 5: Algorithm Block Format
  Before: Large algorithm environment with full algorithmic package
  After:  Compact verbatim block with tighter spacing

  Impact:
  - Fits better in IEEE column format
  - Reduced from ~30 lines to ~15 lines
  - Still maintains clarity and logic
  - Properly escaped operators
